## Descrição
Foi desenvolvido uma aplicação web (responsiva) de música referente ao Checkpoint 5 da matéria de Front, no qual implementamos o framework Tailwindcss, e a API SoundCloud, para tocar música sem copyright. 

## Tecnologia utilizada
- HTML, CSS
- Tailwind (framework-css)
- API SoundCloud
